## 📌 Overview

This project presents an intelligent Intrusion Detection System (IDS) for cloud environments using advanced Machine Learning techniques.

The objective is to compare multiple state-of-the-art models on the **NF-UQ-NIDS-v2** dataset and identify the most effective approach for detecting malicious network traffic.

## 📊 Results

| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC |
|--------|----------:|----------:|--------:|----------:|---------:|
| XGBoost | 98.85% | 99.40% | 98.87% | 99.14% | 99.89% |
| LightGBM | 98.79% | 99.37% | 98.82% | 99.09% | 99.89% |
| CatBoost | 98.50% | 99.12% | 98.63% | 98.87% | 99.84% |

## 📂 Dataset

This project uses the **NF-UQ-NIDS-v2** dataset.

The dataset is not included in this repository because of its size.

Download it from Kaggle:
